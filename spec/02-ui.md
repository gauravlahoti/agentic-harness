## Design baseline (keep in every stage)

Agreed with you on 2026-11-10. New stages **add** to this; they never replace or drop it. `tests/unit/test_page_baseline.py` fails if a piece disappears.

| Piece | Must stay |
|---|---|
| Agent view | Calm chat: task bubble (top right) → agent header (loop-ring mark · workspace name · "Activity" · live counters: calls · tokens · $ · s) → Activity lines → prose answer → run footer ("✓ Run complete" / "■ Stopped: …" / "✗ Failed: …") |
| Activity lines | Dot + thin connector, colour by harness part, small part tag (LOOP, TOOL, CONTEXT, later GUARDRAIL…), a risk tag on tool lines (read · write · action), chevron that opens plain facts first and "Raw event" below |
| Files | A card under the answer for every file a tool saved (draft, or outbox "not sent"); it opens to the text |
| Input box | Docked at the bottom with a soft fade above; animated model menu (customizable `<select>`, opens upward, bold + check on the current model); round ↑ send |
| Wording | No helper phrases ("select a model", "runs on…"). Text appears only when something needs attention (e.g. no key) |
| Theme | Follows the system; sun/moon toggle with circular reveal (D-28); every colour a `light-dark()` pair |
| Sidebar | Pinned to the window (toggle never scrolls away); Agent, Memory, Evals, Golden Dataset and Checks pages in a card with a highlight that glides to the current page and a harness-colour dot per page (S10); Chats (was "Your work") and Workspace (the page links) fold under their headings, remembered per browser (S10, your request) |
| Safety | All text set as text, never HTML; strict content-security policy; reduced motion respected |
| Models | Only Gemini answers (D-32); the menu lists priced models only (D-31) |

## Pieces

| Piece | What it shows |
|---|---|
| **Profile switcher** (sidebar top + chip in input box) | Sales · Engineering · Finance · CFO. Switching starts a fresh task under that profile |
| **Your work** | This profile's saved tasks: open, continue, delete |
| **Activity timeline** | One plain-language line per step, a tag for the part that acted, ⌄ to open details |
| **Guardrail cards** | ⛔ blocked (with the rule) · ⚠ flagged · ⏸ approval (action, values, reason, evidence, who can approve) |
| **Answer** | Summary → Needs a human decision → Sources (record IDs, skill path, policy section) |
| **File cards** | Drafts saved in the task folder; open in a side panel |
| **Status line** | "Working on it" → "Run complete · nothing was sent" |
| **Header meter** | Mini loop ring (lights the active part) · steps · tokens · $ · context fill |
| **X-ray** | Per step: what Gemini saw, tool input/output, the gate's decision and rule, tokens and cost |
| **Replay** | Plays any saved task on the same screen, with zero API calls |

## Colors: one per harness part

| Part | Color |
|---|---|
| Loop | Neutral gray |
| Context | Blue |
| Actions (tools, sub-agent) | Green |
| Guardrails | Amber (⏸ ⚠) · Red (⛔) |
| Memory | Purple |

Follows the system theme; a sun/moon toggle in the sidebar overrides it, with a circular reveal (D-28). Reduced motion respected. Plain HTML/CSS/JS, no build step.
